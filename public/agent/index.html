Remote Monitoring & Management Agent - Installationsanleitung

Voraussetzungen

Betriebssystem Mindestanforderungen
Windows Windows 10/11, Windows Server 2016+, PowerShell 5.1+
Linux Ubuntu 18.04+, Debian 10+, CentOS 7+, curl, jq, bc installiert

Schritt 1: Enrollment-Token generieren

1

Öffnen Sie das IT REX ServiceDesk und navigieren Sie zu RMM → Übersicht

2

Klicken Sie auf + Enrollment-Token

3

Wählen Sie die Organisation und den Gerätetyp

4

Kopieren Sie den generierten Token (z.B. ITREX-ABC123DEF-456GHI)

Schritt 2: Agent installieren

Windows Installation (PowerShell)

Tipp: Führen Sie PowerShell als Administrator aus!

Option 1: Direkt ausführen

# Agent herunterladen und starten
$token = "IHR-ENROLLMENT-TOKEN"
$server = "https://ihr-servicedesk.domain.de"

Invoke-WebRequest -Uri "$server/agent/itrex-rmm-agent.ps1" -OutFile "C:\Temp\itrex-rmm-agent.ps1"
Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process
& "C:\Temp\itrex-rmm-agent.ps1" -EnrollmentToken $token -ServerUrl $server

Option 2: Als Windows-Dienst installieren

# Als geplante Aufgabe registrieren (startet bei Systemstart)
$action = New-ScheduledTaskAction -Execute "powershell.exe" -Argument "-ExecutionPolicy Bypass -File C:\Temp\itrex-rmm-agent.ps1 -EnrollmentToken IHR-TOKEN -ServerUrl https://ihr-server.de"
$trigger = New-ScheduledTaskTrigger -AtStartup
$settings = New-ScheduledTaskSettingsSet -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries
Register-ScheduledTask -TaskName "IT REX RMM Agent" -Action $action -Trigger $trigger -Settings $settings -User "SYSTEM" -RunLevel Highest
⬇️ Windows Agent herunterladen

Linux Installation (Bash)

Voraussetzungen installieren:
sudo apt-get install -y curl jq bc

Installation:

# Agent herunterladen und ausführen
TOKEN="IHR-ENROLLMENT-TOKEN"
SERVER="https://ihr-servicedesk.domain.de"

curl -o /opt/itrex-rmm-agent.sh "$SERVER/agent/itrex-rmm-agent.sh"
chmod +x /opt/itrex-rmm-agent.sh
sudo /opt/itrex-rmm-agent.sh -t "$TOKEN" -s "$SERVER"

Als Systemd-Service installieren:

# Systemd Service erstellen
sudo tee /etc/systemd/system/itrex-rmm-agent.service > /dev/null << EOF
[Unit]
Description=IT REX RMM Agent
After=network.target

[Service]
Type=simple
ExecStart=/opt/itrex-rmm-agent.sh -t IHR-TOKEN -s https://ihr-server.de
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
EOF

# Service aktivieren und starten
sudo systemctl daemon-reload
sudo systemctl enable itrex-rmm-agent
sudo systemctl start itrex-rmm-agent
⬇️ Linux Agent herunterladen

Schritt 3: Überprüfen

✓

Öffnen Sie RMM → Geräte im ServiceDesk

Das neue Gerät sollte mit Status 🟢 Online erscheinen

Agent-Funktionen

Funktion Beschreibung Intervall
Heartbeat CPU, RAM, Disk-Auslastung, Uptime 60 Sekunden
Inventar Hardware- und Software-Inventar Stündlich
Jobs Remote-Skripte und Deployments ausführen Bei Heartbeat geprüft

Fehlerbehebung

Agent registriert sich nicht?
  • Prüfen Sie, ob der Token noch gültig ist
  • Stellen Sie sicher, dass der Server erreichbar ist
  • Prüfen Sie die Firewall-Einstellungen (HTTPS Port 443)

Log-Dateien:

  • Windows: C:\ProgramData\ITREX-RMM\agent.log
  • Linux: /var/log/itrex-rmm-agent.log
